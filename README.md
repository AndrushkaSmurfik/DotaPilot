# DotaPilot

Десктоп-помощник для Dota 2: оверлей с таймерами, голосовые оповещения, карточка после матча и мягкий анти-тильт.
Работает **только** через официальный Valve Game State Integration (GSI).

## Возможности (MVP)

| Функция | Что делает |
|---|---|
| Онбординг | Находит Dota 2 через реестр Steam и `libraryfolders.vdf`, создаёт `game/dota/cfg/gamestate_integration/gamestate_integration_dotapilot.cfg` со случайным токеном. Если не нашёл — ручной выбор папки. |
| Оверлей | Прозрачное окно поверх игры, клики проходят насквозь. Таймеры по `map.clock_time`: руны богатства/силы/мудрости, стаки (xx:53), лотосы, тормент, день/ночь, тиры нейтралок. |
| Ручные таймеры | Рошан (респавн 8–11 мин), аегис (5 мин), глиф врага (5 мин) — запускаются вашим глобальным хоткеем. |
| Голос | Web Speech API, вкл/выкл и «за сколько секунд» для каждого таймера. |
| Пост-матч | При `POST_GAME` берёт `match_id`, грузит OpenDota: KDA, GPM/XPM, LH на 10-й минуте против медианы героя, тайминги предметов. Если матч не распарсен — запрашивает разбор и опрашивает каждые 30 с. |
| Анти-тильт | Серия поражений, длительность сессии, мягкие предложения сделать перерыв, напоминание похвалить тиммейтов (только текст). |
| Напоминание о репорте | Хоткей «отметить токсика» запоминает момент матча. После игры — уведомление со временем отметок и шагами, как отправить жалобу. Репорт отправляете вы сами: чат GSI не передаёт, а DotaPilot ничего не нажимает. |
| Байбек | Строка в оверлее: «готов», «не хватает N золота» или откат (`hero.buyback_cost/cooldown` из GSI). |
| Тормент | Хоткей «тормент убит» → таймер респавна 10 мин. |
| История | Все сыгранные матчи, общий винрейт и статистика по героям; из списка — сразу в разбор. |
| Конфиги | Библиотека `.cfg`: загрузите несколько, выберите один — он записывается в `game/dota/cfg/autoexec.cfg` вместо старого. Исходный autoexec сохраняется резервной копией перед первой заменой. Срабатывает при следующем запуске Dota или по `exec autoexec` в консоли. |
| Трей и автозапуск | Крестик сворачивает в трей (оверлей продолжает работать), меню трея: показать/скрыть оверлей, переместить, выход. Опционально — автозапуск с Windows. |
| Уведомления | Тосты Windows после матча: серия поражений, долгая сессия, репорт. |
| Pro | Экран подписки (299 ₽/мес, 2 390 ₽/год — оплата пока не подключена), feature-flag `isPro`, ИИ-разбор матча через прокси с Claude. |

## Установка

Требования (Windows 10/11):

1. [Node.js](https://nodejs.org) 22+ (нужен для `node:sqlite` в мок-скрипте и `--env-file-if-exists`).
2. [Rust](https://rustup.rs) (stable) и **Visual Studio Build Tools** с компонентом «Desktop development with C++».
3. WebView2 (в Windows 11 уже есть).

```bash
npm install
npm run tauri dev
```

Сборка инсталлятора: `npm run tauri build`.

### Настройка Dota 2

1. При первом запуске пройдите онбординг — DotaPilot создаст конфиг GSI.
2. Steam → Dota 2 → Свойства → Параметры запуска: добавьте `-gamestateintegration`.
3. В игре выберите режим экрана **«Окно без рамки»** — поверх эксклюзивного полноэкранного режима никакое окно не отображается.
4. Перезапустите Dota 2.

### Хоткеи по умолчанию

| Действие | Сочетание |
|---|---|
| Рошан убит (старт Рошан + аегис) | `Alt+R` |
| Враг нажал глиф | `Alt+G` |
| Тормент убит (респавн 10 мин) | `Alt+M` |
| Отметить токсичное поведение (напоминание о репорте) | `Alt+T` |
| Свои таймеры | задаются на вкладке «Таймеры» |
| Режим настройки оверлея (перетаскивание) | `Ctrl+Alt+O` |
| Сбросить ручные таймеры | `Ctrl+Alt+Backspace` |

Меняются в «Настройки → Оверлей и хоткеи»: кликните по полю и нажмите сочетание.

Глобальный хоткей перехватывается целиком: игра его не получит, а если сочетание уже занято другой программой, DotaPilot не сможет его назначить и покажет это в оверлее. Типичные конфликты: `Alt+R` у оверлея NVIDIA (счётчик производительности) и alt-каст ультимейта в Dota.

### Вкладка «Таймеры»

- **Запущенные** — только активные таймеры (Рошан, аегис, глиф, тормент и ваши) с остатком времени и кнопкой «Остановить».
- **Запуск** — кнопки для встроенных и ваших таймеров (то же, что хоткеи).
- **Глиф на зарядах** — выберите, сколько зарядов глифа у противника (1 или 2). Каждое нажатие тратит заряд, заряды возвращаются по одному раз в 5:00 (как зарядные способности в Dota). Оверлей показывает «Глиф врага 0/2 → 1/2» и озвучивает возврат каждого заряда. Нажатие, когда по таймеру зарядов нет, считается верным и перезапускает восстановление.
- **Мои таймеры** — создавайте свои: название, длительность (мм:сс), за сколько секунд предупредить, хоткей, озвучка. Ваши таймеры показываются в оверлее со значком ◆ вместе с рунами и стаками; в матче идут по игровым часам (пауза их останавливает), вне игры — по обычному времени.

## Разработка без игры (мок-режим)

Запустите приложение (`npm run tauri dev`), затем во втором терминале:

```bash
npm run mock:gsi                                # симуляция матча с -1:30 до 40:00, x10
npm run mock:gsi -- --speed 30 --from 5:30 --to 12:00 --lose
npm run mock:gsi -- fixtures                     # проиграть fixtures/gsi/*.json по порядку
npm run mock:gsi -- bad-token                    # убедиться, что неверный токен → 401
```

Порт и токен скрипт берёт из базы приложения (`%APPDATA%\com.dotapilot.app\dotapilot.db`), либо из `--port/--token` или `DOTAPILOT_TOKEN`.
В конце симуляции отправляется `POST_GAME` с реальным `match_id` 9065883621, поэтому пост-матч карточка открывается на настоящих данных OpenDota.

## ИИ-разбор матча (Pro)

Клиент обращается только к прокси, ключ Anthropic хранится только в `proxy/.env`:

```bash
copy proxy\.env.example proxy\.env   # впишите ANTHROPIC_API_KEY
npm run proxy
```

Прокси вызывает Claude Opus 5.5 (`claude-opus-5-5`) со строгой JSON-схемой ответа и серверным fallback-ом на случай отказа модели. Без ключа (или с `AI_MOCK=true`) отдаёт демо-ответ. В приложении включите флаг `isPro` на экране Pro.

## Структура

```
src-tauri/src/gsi/      GSI-сервер (axum, 127.0.0.1), проверка токена, serde-типы, события в фронт
src-tauri/src/setup/    Поиск Steam/Dota (VDF-парсер), запись cfg
src/features/timers     Чистые функции таймеров от clock_time + константы патча (config.ts)
src/features/postmatch  Клиент OpenDota, анализ, карточка
src/features/tilt       Серия/сессия, сообщения, наблюдатель конца матча
src/features/settings   Модель настроек (SQLite), онбординг, экран настроек
src/features/pro        Feature-flag, ИИ-разбор (клиент к прокси + мок), экран подписки и цены
src/features/reports    Отметки токсичного поведения и напоминание о репорте
src/features/history    История матчей и статистика по героям
src/features/configs    Экран библиотеки конфигов autoexec
src/features/custom     Свои таймеры, захват хоткеев, вкладка «Таймеры»
src-tauri/src/setup/configs.rs  Импорт, применение и резервная копия autoexec.cfg
src-tauri/src/tray.rs   Значок в трее и его меню
src/overlay             Окно оверлея: click-through, перетаскивание, хоткеи, озвучка
scripts/mock-gsi.mjs    Мок-клиент GSI
fixtures/               GSI-payload и срез реального матча OpenDota
proxy/                  Прокси ИИ-разбора (ключ Anthropic только здесь, в .env)
```

После игрового патча обновите `src/features/timers/config.ts` — все тайминги лежат там.

## Почему это безопасно для аккаунта (только GSI)

- **Game State Integration — официальный механизм Valve.** Dota 2 сама читает файл из `cfg/gamestate_integration/` и сама отправляет JSON на указанный адрес. Им пользуются стримерские оверлеи и турнирные трансляции.
- **Никакого доступа к процессу игры.** DotaPilot не читает и не пишет память, не внедряет DLL, не перехватывает отрисовку и не трогает файлы игры, кроме одного текстового cfg.
- **Никакой автоматизации.** Приложение не нажимает клавиши, не двигает мышь и не отправляет ничего ни в игру, ни в чат, ни в систему репортов. Глобальные хоткеи только запускают таймеры внутри DotaPilot.
- **Чат не читается.** GSI не передаёт сообщения чата, а читать их из памяти игры мы принципиально не станем. Поэтому напоминание о репорте работает по вашей отметке хоткеем, а сам репорт вы отправляете вручную.
- **Только разрешённые данные.** Конфиг запрашивает лишь `provider`, `map`, `player`, `hero`. В обычной игре GSI не отдаёт информацию о врагах, которую игрок не видит.
- **Локально и с токеном.** Сервер слушает только `127.0.0.1`. Запросы без правильного токена отклоняются (`401`), и токен не уходит в интерфейс.
- **Внешние данные — только публичные API.** После матча используется публичный OpenDota API. Ключ ИИ хранится на сервере-прокси, а не в клиенте.

Оверлей показывает то, что игрок и так может посчитать сам (таймеры от игровых часов). Это вспомогательная информация, а не преимущество за счёт скрытых данных.
